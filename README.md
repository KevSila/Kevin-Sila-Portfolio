package.json: Configuration for project dependencies and build scripts.

## ⚙️ Local Development
To run this portfolio on your own machine:

Clone the repo:

Bash
git clone https://github.com/KevSila/Kevin-Sila-Portfolio.git
cd Kevin-Sila-Portfolio
Install dependencies:

Bash
npm install
Launch the local server:

Bash
npm start
