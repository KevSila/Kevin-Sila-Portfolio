# Kevin Yumbya Sila — Professional Portfolio

Source code for **https://kevsilaportfolio.netlify.app/**.

This portfolio presents my work across ICT, research and evidence systems, business systems, AI-enabled workflows, dashboards, digital transformation, web development, and operational intelligence.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Motion
- Netlify

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Netlify publishes the Vite `dist` directory. Search-engine crawler assets such as `robots.txt`, `sitemap.xml`, and the Google Search Console verification file are stored in `public/` and copied into the production build.
